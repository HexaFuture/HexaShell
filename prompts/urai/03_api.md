# 3. robot API

- robot.goto(arm, xyz=None, by=None, pitch=None, yaw=None, roll=None, grip=None, path="auto", dry_run=False, contact=False, gentle=False): arm is left/right; xyz accepts a 3-tuple, Spot or ArmStatus. Without xyz the measured TCP is used; by is a world-frame offset from that position. grip is sent when the motion starts; to put an object down, call gripper separately after arriving. Returns Move: ok/reached/moved/at/angles/err_mm/err_deg/steps/path/notes.
- path="line" asks for a strict Cartesian straight line; "swing" asks for a joint-space curve; "auto" tries the line first and, if that fails, accepts only a joint curve that stays within 3 cm of the line and no more than 1 cm below the lower of the two ends; beyond that you need an intermediate point or an explicit swing.
- dry_run=True only plans: it does not restore CAN, sends no motion or gripper command and uses no budget; Move.steps gives the expected number of steps, and a refusal returns reached=False. An ordinary planning refusal raises NotExecuted and cuts the current cell short; a URAI result with result.outcome="empty_grasp" maps to Dropped; execution errors without a structured classification keep their original message, and Blocked/Dropped are never guessed from error text.
- contact=True means no harness stall check; URAI's collision and tracking checks still apply. This profile has no extra in-motion slip detection. gentle=True caps the whole motion at the original H v1 endpoint speed limit of 0.5 m/s, without speeding up mid-path; URAI's stricter angular and joint limits still apply. When the default session speed is below that cap, nothing is slowed further.
- robot.gripper(arm, opening): open/close/0..1; changes the opening while holding the pose and returns Grip. Closing on air is legal; check holding and width_m before lifting.
- robot.home(arm="both"): left/right/both; plans through URAI back to the session's initial joints, keeps the gripper, returns Homing.
- robot.wait(n): n=1..200; holds in URAI for n*0.04 s; returns Waited, whose steps include the actual scheduling overhead.
- robot.to_world(cam, xy, z=None, pair=None): reads the frame's full depth by default; z is a horizontal world plane; pair=(cam2,xy2) triangulates from two views. Returns Spot; with missing depth xyz=None, and the table is not assumed.
- robot.to_pixel(xyz, cam="head"): projects to a pixel; returns None outside the view or behind the lens.
- robot.task: the task, budget and session start pose. robot.state(): measured TCP, angles, joints, opening and holding of both arms.
- robot.image(cam="head"): the current uint8 RGB array. robot.camera(cam="head"): the current camera's full K and world pose.
- robot.look(cams="head", grid=False, marks=None, masks=None, crop=None, zoom=None, tile=False, note=None): attaches pictures to the cell. cams can be a list or all; world marks use ('world',(x,y,z),'label'); masks accepts supplied outlines; crop=(x0,y0,x1,y1) keeps original image coordinates; tile puts them side by side.
